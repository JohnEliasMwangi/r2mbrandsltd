CONGENIAL - SITE FONT
=====================

The whole site is set in "Congenial" (Laura Worthington). It is a licensed
commercial font, so the font files are NOT bundled here. Add them to this
folder and the site picks them up automatically - no code changes needed.

File names expected by assets/css/styles.css
(.woff2 is preferred; .woff or .otf also work):

  Congenial-Regular.woff2   -> weight 400 (body text)
  Congenial-Medium.woff2    -> weight 500
  Congenial-Bold.woff2      -> weight 700 (weights 600 also map here)
  Congenial-Heavy.woff2     -> weight 800 (headings / buttons)
  Congenial-Black.woff2     -> weight 900 (big headlines)

Web-font kits usually ship with different names (e.g. congenial-bold-webfont.woff2).
Just rename them to the names above.

Make sure your license covers "Web Font" use for this domain.
If a file is missing, the browser falls back to a system sans-serif for
that weight only.
